# 栈
## 顺序栈
### 定义
由一个指向数组的指针、最大长度数值和栈顶的数组下标组成。
```c
typedef struct{
  data_t* data;
  int maxlen;
  int top;
}sqstack;

```
### 创建
1. 申请内存。要申请两块——一个是栈的内存空间，另一个是data对应数组的内存空间。
```c
sqstack* sqstack_create(int max){
  sqstack* s;
  if((s = (sqstack*)malloc(sizeof(sqstack))) == NULL){
    printf("malloc failed.\n");
    return NULL;
  }

  if((s->data = (data_t*)malloc(max * sizeof(data_t))) == NULL){
    printf("malloc failed.\n");
    return NULL;
  }
}
```
**Tips:**
（已错）注意在判定s->data无效时，要释放。
```c
//if((s->data = (data_t*)malloc(max * sizeof(data_t))) == NULL){

    free(s);

//...
```

2. 赋初值。用memset函数将data数组全部值赋为0（需要引用string库），top赋为-1。
```c
#include <string.h>
memset(s->data, 0, max * sizeof(data_t));
s->top = -1;
s->maxlen = max;

return s;
```

### 推入栈。
1. 考虑特殊情况——栈是否创建成功或是否满。
```c
int sqstack_push(sqstack* s, data_t value){
  if(s == NULL || s->data == NULL){
    printf("The stack you create malloc failed, please check!\n");
    return -1;
  }

  if(s->top == s->maxlen-1){
    printf("The stack is full.\n");
    return -1;
  }
}
```

2. 改变top值，将目标值加入data数组。
```c
s->top++;
s->data[s->top] = value;

return 0;
```

### 判断栈是否空
1. 先考虑特殊情况——内存申请失败。
```c
int sqstack(sqstack* s){
  if(s == NULL || s->data == NULL){
    printf("The stack you create malloc failed, please check!\n");
    return -1;
  }
}
```

2. 利用top值可判断。
```c
if(s->top == -1){
  printf("The stack is empty.\n");
  return 0;
}
```
**Tips:**
（已错）漏掉了非空的情况，此时非空没有返回值。
```c
  return (s->top == -1) ? 1 : 0;
```

### 栈顶
1. 排除特殊情况，返回top对应的值。
```c
data_t sqstack_top(sqstack* s){
  if(s == NULL || s->data == NULL){
    printf("The stack you create malloc failed, please check!\n");
    return 0;
  }
  
  if(s->top == -1){
    printf("The stack is empty.\n");
    return 0;
  }

  return s->data[s->top];
}
```

### 推出栈
1. 排除特殊情况，返回推出的值。
```c
data_t sqstack_pop(sqstack* s){
  if(s == NULL || s->data == NULL){
    printf("The stack you create malloc failed, please check!\n");
    return 0;
  }
  
  if(s->top == -1){
    printf("The stack is empty.\n");
    return 0;
  }

  data_t t = s->data[s->top];
  s->data[s->top] = 0;
  s->top--;

  return t;
}
```

### 清空栈
1. 排除特殊情况。
```c
int sqstack_clear(sqstack* s){
  if(s == NULL || s->data == NULL){
    printf("The stack you create malloc failed, please check!\n");
    return -1;
  }
  
  if(s->top == -1){
    printf("The stack is empty.\n");
    return -1;
  }
}
```

2. 遍历栈，从top逐步pop掉。
```c
while(s->top >= 0)
  sqstack_pop(s);

return 0;
```
**Tips:**
pop操作不需要进行free操作，因为申请的是整个（最大数maxlen）空间的内存，只需在程序结束或clear时free。
（改进）只需将top置为-1即可。
```c
s->top = -1;

return 0;
```

### 释放顺序栈
1. 考虑特殊情况，先释放data,防止野指针，最后释放s。
```c
int sqstack_free(sqstack* s){
  if(s == NULL || s->data == NULL){
    printf("The stack you create malloc failed, please check!\n");
    return -1;
  }

  free(s->data);
  s->data = NULL;
  free(s);
  s = NULL;

  return 0;
}
```
**Tips:**
s在这里是形参，释放掉对外部无效，返回空指针，在主函数中用s = sqstack_free(s)即可置空。
```c
sqstack* sqstack_free(sqstack* s){
  if(s == NULL)
    return NULL;

  if(s->data != NULL)
    free(s->data);

  free(s);

  return NULL;
}
```
