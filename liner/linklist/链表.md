# 链表
## 定义
由某个数据结构的数据data和next指针构成。需要定义头指针head,数据定为0。
```C
typedef int data_t;
typedef struct node{
  data_t data;
  struct node* next;
}node, *linklist;
```
**Tips**:注意这里不要缩写，next指针指向的是下一个结点而不是数据。

## 构造
1. 输出为链表的头指针。
```C
linklist linklist_create();
```
2. 申请内存分配。注意引用stdlib库。
```C
#include <stdlib>
L = (linklist)malloc(sizeof(node));
if(L == NULL){
  printf("malloc failed.\n");
  return L;
}
```
**Tips**:sizeof()函数后面应该跟的是具体的数据类型而不是指针，不要写成sizeof(linklist)了，可以写成sizeof(*linklist)。

3. 初始化值。
```C
H->data = 0;
H->next = NULL;
```

4. 返回。
```C
return H;
```

## 尾插法
1. 输入链表的头指针、数据数值。返回-1为失败，0为成功。
```C
int linklist_tail_insert(linklist H, data_t value);
```
2. 判断特殊情况——内存分配失败。
```C
if(H == NULL){
  printf("Your previous malloc has failed, please check!\n");
  return -1;
}
```

3. 创建新结点。
```C
linklist p;
if((p = (linklist)malloc(sizeof(node))) == NULL){
  printf("malloc failed.\n");
  return -1;
}
p->data = value;
p->next = NULL;
```
**Tips:**
注意if里面的语句是先执行后判断，但是执行部分的语句要加上括号。

4. 找到尾结点，使其next指针指向新结点,即可完成插入。
```C
linklist q = H;
for(;q->next != NULL;q = q->next);
q->next = p;
return 0;
```

## 遍历链表
1. 为了验证算法是否符合要求，需要遍历链表满足可视化要求。输入是链表的头指针。
```C
void linklist_show(linklist H);
```

2. 判断特殊情况——内存分配失败或链表为空。
```C
if(H == NULL){
  printf("Your previous malloc has failed, please check!\n");
  return;
}
 
if(H->next == NULL){
  printf("The linklist is empty.\n");
  return;
}
```

3. 遍历链表。
```C
linklist p;
for(p = H;p->next != NULL;p = p->next){
  printf("%d ", p->next->data);
}
puts("");
return;
```
**Tips:**
p从头指针开始遍历，到p的next指针为空，即尾结点则停止。打印时注意是打印指针next的数值。

## 指定位置插入
1. 实现像顺序表的指定插入方式,输入为链表的头指针、位置坐标和数值。
```C
int linklist_insert(linklist H, int pos, data_t value);
```

2. 在此之前，要先实现找到链表指定位置的函数,输入为头指针和位置坐标，输出该位置的结点指针。
```c
linklist linklist_get_position(linklist H, int pos);
```

3. 先考虑特殊情况——内存分配失败和链表为空。
```c
//linklist_get_position函数
if(H == NULL){
  printf("Your previous malloc has failed, please check!\n");
  return NULL;
}
 
if(H->next == NULL){
  printf("The linklist is empty, use tail insert please.\n");
  return NULL;
}
```

4. p从头指针开始，找位置i的结点，需要找i+1次。
```c
//linklist_get_position函数
linklist p = H;
for(int i = 0;i <= pos;i++){
  p = p->next;
  if(p == NULL){
    printf("The input position is invalid.\n");
    return NULL;
  }
}

return p;
```
此时p有两种情况：位置有效的话，则能找到指定结点;反之则位置无效。
**Tips:**
注意不要忘了赋值p,不然是野指针。
还有一种特殊情况——pos<-1时它会直接返回头指针，因此要多考虑一种情况。
```c
// ...if(H->next == NULL)...
if(pos < -1){
  printf("The input position is invalid.\n");
  return NULL;
}
// ...linklist p = H...
```

5. 创建新结点，先将新结点指向指定位置，保证原链表逻辑不变，再让pos-1的结点指向新结点。
```c
//linklist_insert函数
linklist p = linklist_get_position(H, pos-1);
if(p == NULL)
  return -1;

linklist q;
if((q = (linklist)malloc(sizeof(node))) == NULL){
  printf("malloc failed.\n");
  return -1;
}
q->next = p->next;
p->next = q;

return 0;
```

## 链表结点删除
1. 与插入结点类似，输入为链表的头指针和位置。
```c
int linklist_delete(linkllist H, int pos);
```

2. 考虑特殊情况——内存分配失败和链表为空。
```c
if(H == NULL){
  printf("Your previous malloc has failed, please check!\n");
  return -1;
}
 
if(H->next == NULL){
  printf("The linklist is empty.\n");
  return -1;
}
```

3. 检查pos是否有效——找pos-1的结点，如果它是尾节点则为无效。
```c
linklist p = linklist_get_position(H, pos-1);
if(p == NULL || p->next == NULL){
  printf("The input position is invalid.\n");
  return -1;
}
```
**Tips:**
if里面应该先判断是否为空，再取成员。

4. 删除操作——将pos-1的结点的next赋值目标结点的next。
```c
linklist q = p->next;
p->next = q->next;
```

5. 释放内存空间。
```c
free(q);
q = NULL;

return 0;
```

## 释放链表
1. 在删除一个结点时，我们当时释放掉了那个结点的空间，如果我们的程序已经结束，一个一个删除太麻烦，因此需要一个释放掉整个链表的函数。
```c
linklist linklist_free(linklist H);
```
**Tips:**
为什么返回linklist：因为我们在遍历删除时，H会被赋值为H->next。最终需要将H置为空，才不会影响后续操作的判断。但是在函数中的H是形参，如果在函数中置空就只是将函数中的H置空，不影响主函数中的H，这样释放函数就没有意义了。因此我们直接返回一个空指针才能达到要求。

2. 考虑特殊情况——内存分配失败。
```c
if(H == NULL){
  return NULL;
}
```

3. 遍历释放空间。
```c
linklist temp;

while(H != NULL){
  temp = H->next;
  free(H);
  H = temp;
}
puts("");

return NULL;
```

## 反转链表
1. 输入一个链表，将其反转。
```c
linklist linklist_turn(linklist H);
```

2. 判断链表是否有效/为空/一个结点。
```c
if(H == NULL){
  printf("H = NULL.\n");
  return NULL;
}

if(H->next == NULL || H->next->next == NULL)
  return H;
```

3. 分离出第一个结点和链表剩余的部分，用一个临时指针p指向剩余部分。
```c
linklist p = H->next->next;
```
**Tips:**
注意一定要将第一个结点和链表剩余的部分分离开！不然会进入死循环（已犯）。
```c
H->next->next = NULL;
```

4. 将p链表从头用头插法加入第一个结点。
```c
linklist q;
while(p != NULL){
  q = p;
  p = p->next;
  q->next = H->next;
  H->next = q;
}

return H;
```

## 求相邻结点最大值
1. 求出相邻结点数据的最大值，并返回第一个结点和最大值。由于只能有一个返回值，因此在输入值中定义一个指针用于记录最大值。
```c
linklist linklist_adjmax(linklist H, data_* value);
```

2. 考虑特殊情况——H为空、链表为空、只有一个结点和只有两个结点。
```c
if(H == NULL){
  printf("H = NULL.\n");
  return NULL;
}

if(H->next == NULL || H->next->next == NULL || H->next->next->next == NULL)
  return NULL;
```

3. 用r记录第一个结点，记录下相邻结点的和并与前极大值对比。
```c
linklist p, r;
p = H->next;
r = p;
*value = p->data + p->next->data;

while(p->next != NULL){
  p = p->next;
  if(*value < p->data + p->next->data){
    *value = p->data + p->next->data;
    r = p;
  }
}

return r;
```
**Tips:**
注意while里面用p->next而不是q,防止野指针。
上面的函数是错的，因为在while循环后p向后移动了，因此虽然你判断了原来的p->next不为空，但是后来如果p是空的，还是成了野指针。因此应该像下面这样写：
```c
linklist p, r;
p = H->next;
r = p;
*value = p->data + p->next->data;

while(p->next != NULL){
  data_t sum = p->data + p->next->data;
  if(*value < sum){
    *value = sum;
    r = p;
  }
  p = p->next;
}

return r;
```
但是这样会多算一次，且不够规范。更好的写法应该是用双指针滑动窗口：
```c
linklist p, q, r;
p = H->next;
q = H->next->next;
*value = p->data+q->data;
r = p;

while(q->next != NULL){
  p = p->next;
  q = q->next;

  if(*value < p->data + q->data){
    *value = p->data + q->data;
    r = p;
  }
}

return r;
```

## 有序链表合并
1. 将两条单调递增的链表H1, H2合并，合并后的链表H1依然是单调递增的。
```c
int linklist_merge(linklist H1, linklist H2);
```

2. **Tips:**
判断特殊情况——H1或者H2有一个为空。
```c
if(H1 == NULL || H2 == NULL)
  return -1;
```

3. 分别用p、q分别遍历H1和H2,再将两个链表置空，用r记录H1的尾结点。
```c
linklist p = H1->next;
linklist q = H2->next;
linklist r = H1;
H1->next = NULL;
H2->next = NULL;

while(p && q){
  if(p->data < q->data){
    r->next = p;
    p = p->next;
    r = r->next;
  }
  else{
    r->next = q;
    q = q->next;
    r = r->next;
  }
}

if(p == NULL)
  r->next = q;
else
  r->next = p;

return 0;
```
**Tips:**
更美观的写法：
```c
//while(p && q){...}

r->next = p ? p : q;//三目运算符

return 0;
```
