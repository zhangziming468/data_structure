# 顺序表

## 定义

由某个数据类型的**一维数组data[N]和尾坐标last**构成。注意要宏定义**上限N**。

```c
typedef struct{
  int data[N];
  int last;
}sqlist, *sqlink;
```

## 构造

1. **申请内存分配。**若分配失败*（内存泄漏）*，L为空指针。打印失败信息并返回L；

   ```c
   #include <stdlib.h>
   L = (sqlink)malloc(sizeof(sqlist));
   if(L == NULL){
     printf("malloc failed\n");
     return L;
   }
   ```

2. **初始化。**顺序表中全部元素置0，last取-1。

   ```c
   #include <string.h>
   memset(L, 0, sizeof(sqlist));
   L->last = -1;
   ```

3. **返回**L作为结果。

   ```c
   return L;
   ```

## 清空

1. **判断顺序表是否有效。**

   ```c
   if(L == NULL){
     return -1;
   }
   ```

2. **判断是否为空。**

   ```c
   if(L->last == -1){
     printf("the list is empty.\n");
     return -1;
   }
   ```

3. **将所有元素置0，last置-1**

   ```c
   memset(L, 0, sizeof(sqlist));
   L->last = -1;
   ```

4. **返回**

   ```c
   return 0;
   ```

## 判断是否为空

1. **判断顺序表是否有效。**

   ```c
   if(L == NULL){
     return -1;
   }
   ```
   
1. **判断last是否等于-1。**

   ```c
   if(L->last == -1){
     return 1;
   }
   else{
     return 0;
   }
   ```

## 插入

1. **判断顺序表是否有效。**

   ```c
   if(L == NULL){
     return -1;
   }
   ```

2. **判断是否满。**

   ```c
   if(L->last == N-1){
     printf("The list is full\n");
     return -1;
   }
   ```

3. **判断pos是否有效。**pos的取值范围应为[0, last+1]。

   ```c
   if(pos < 0 || pos > (L->last)+1){
     printf("The input position is invalid\n");
     return -1;
   }
   ```

4. **顺序表从后到前往后移动，**并更新尾坐标last。

   ```c
   int i;
   for(i = L->last;i >= pos;i--){
     L->data[i+1] = L->data[i];
   }
   L->data[pos] = value;
   L->last++;
   ```

5. **返回。**

   ```c
   return 0;
   ```

## 求并集

1. **判断顺序表是否有效。**

   ```c
   if(A == NULL || B == NULL){
     return -1;
   }
   ```

2. **判断B是否为空。**

   ```c
   if(B->last == -1){
     return -1;
   }
   ```

3. **遍历B，**当A中找不到相同的元素则在A末尾插入。

   ```c
   int i = 0;
   int ret;
   
   while(i <= B->last){
     ret = sqlist_locate(A, B->data[i]);
     if(ret == -1){
       sqlist_insert(A, B->data[i], A->last+1);
     }
     i++;
   }
   return 0;
   ```

## 去重

1. **判断顺序表是否有效。**

   ```c
   if(L == NULL){
     return -1;
   }
   ```

2. **判断是否为空。**

   ```c
   if(L->last == -1){
     printf("the list is empty.\n");
     return -1;
   }
   ```

3. **若表中只有一个元素，**直接返回。

   ```c
   if(L->last == 0){
     return 0;
   }
   ```

4. **双指针i、j，**循环中i固定，j遍历Lj（j < i）。

   ```c
   int i, j;
   for(i = 1;i <= L->last;){
     for(j = i - 1;j >= 0;j--){
       if(L->data[i] == L->data[j]){
         sqlist_delete(L, i);
         break;
       }
     }
     //如果内层循环是因为 break 退出的，j 此时 >= 0，说明发生了删除，i 不能动。
     // 如果内层循环是正常结束的（j < 0），说明前面没有重复元素，i 才可以后移。
     if(j < 0)
       i++;
   }
   ```
